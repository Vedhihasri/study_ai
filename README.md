# Study AI 📚

Study AI is an AI-powered learning platform built using **Retrieval-Augmented Generation (RAG)** to help students understand their study materials through document-based question answering.

### Key Features
- Upload PDF, DOCX, and TXT documents.
- Ask questions and receive context-aware AI answers.
- Hybrid retrieval using semantic and keyword search.
- Source references with filenames and page numbers.
- User authentication and chat-based learning.

### Tech Stack
- **Frontend:** React.js, Vite, JavaScript, Bootstrap
- **Backend:** Python, FastAPI
- **LLM:** Groq
- **RAG & Search:** Sentence Transformers, Pinecone, BM25
- **Database:** PostgreSQL
- **Deployment:** Vercel, Render
